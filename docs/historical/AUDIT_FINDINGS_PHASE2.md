## invariants يجب اختبارها قبل اعتبار الإصلاح ناجحاً

- مصدر السؤال لا يتغير بصمت.
- `manualIdeaId` يغيّر pool فعلياً.
- السؤال المعروض يحتفظ بـ lesson/idea/step metadata.
- نقر الإجابة مرتين لا يضاعف النقاط ولا يمرر الجولة مرتين.
- timeout وclose وrestart لا يتركان timer أو listener.
- كل لعبة بلا درس/طالب/سؤال تعرض حالة قابلة للفهم ولا تبدأ نصف بداية.
