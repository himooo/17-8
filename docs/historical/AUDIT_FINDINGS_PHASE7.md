# تحسينات التخصيص والوصولية — المرحلة السابعة

تم الحفاظ على فلسفة «بسلاسة» القائمة على إدارة حصة بسيطة ومباشرة، مع جعل القرارات الحساسة صريحة للمدرس بدلاً من تنفيذ fallback صامت.

| التحسين | السلوك الجديد |
|---|---|
| مصدر الأسئلة | اختيار الفكرة الحالية/كل الدرس/فكرة محددة يمرر فعلياً إلى الألعاب، مع `aria-pressed` وlabels واضحة |
| نفاد المصدر | لا يعاد السؤال بصمت عند استهلاك كل أسئلة المصدر؛ تظهر حالة فارغة ليختار المدرس مصدراً آخر أو يبدأ جلسة جديدة. يمكن opt-out برمجياً فقط عبر `excludeAsked=false` لمسار مقصود |
| عدد الأسئلة | الإدخال اليدوي مضبوط فعلياً إلى 1–100، لا بمجرد attribute في المتصفح |
| GameOverlay | dialog/alertdialog وaria-modal وaria-label، وإغلاق موحد يمر عبر حارس الجولة النشطة |
| مؤقت الحصة | يبدأ فقط مع `currentSessionId` ويُصفّر عند تبدل الجلسة، مع cleanup |
| مكافآت فورية | حارس 600ms لكل طالب ونوع مكافأة يمنع النقرة المزدوجة من مضاعفة النقاط/الشارات/الهدايا |
| reduced motion/focus | محفوظة من الجولة السابقة في CSS العام وتظل متوافقة مع الألعاب والاحتفالات |

نتائج TypeScript وLint بعد الجولة: ناجحة.
