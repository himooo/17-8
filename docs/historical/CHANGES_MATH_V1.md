# CHANGES — Math Upgrade v1

## السبورة والشرائح

تمت إضافة مفتاح snapshot محلي يعتمد على الدرس والفكرة ورقم الشريحة. عند تغيير الشريحة تُحفظ العناصر الحالية، وعند العودة تُستعاد العناصر الخاصة بها. أُلغي المسح التلقائي عند التنقل حتى لا يفقد المدرس شرحه، بينما يظل المسح اليدوي وتراجع/إعادة متاحين.

## مختبر الرياضيات

أُضيف `MathToolsPanel` داخل `IframeStage` مع الحاسبة الآمنة، العمليات على الكسور، معاينة المستطيل والدائرة والمثلث، حسابات المساحة والمحيط، الرسم الخطي، الإحصاء، تحويل الوحدات، ومهمات رياضية قصيرة. زر الإدراج يرسل حدثاً دلالياً إلى `SmartWhiteboard`، والنتيجة تدخل في تاريخ Undo/Redo.

## محرك الرياضيات

أُضيف `src/lib/math-engine.ts` بوظائف pure للكسور، الحساب الآمن، الهندسة، الإحصاء، فيثاغورس، الحجوم، وتحويل الوحدات. لا يستخدم `eval`، ويرفض المدخلات غير الآمنة والقسمة على صفر والمقام الصفري.

## الألعاب والمهمات

أُضيف مسار مهمات رياضية تحت سيطرة المعلم داخل مختبر الرياضيات، مع أنماط كسور وهندسة ومعادلات. لا تُسجل نقطة أو خطأ لطالب ما لم يكن هناك طالب حاضر مختار، وتظهر حالة التحقق للمعلم.

## التقارير وPDF

أُضيف `pdf-export.ts` للتقاط عناصر DOM وإنشاء PDF متعدد الصفحات، مع fallback CSS محايد عند وجود ألوان `oklab`/`oklch` من Tailwind. أُضيف PDF لتقرير الطالب، وPDF للشريحة والسبورة، ومركز تقارير يوفّر نسخة الطالب ونسخة المدرس وملخص الصف، مع إبقاء مسار `/grades` الحالي للطباعة والحفظ.

## الاختبارات

أُضيف الأمر `pnpm run test:math`، ويشغّل 17 حالة smoke لمحرك الرياضيات. النتيجة الحالية: 17 ناجحة و0 فشل. TypeScript وBuild ناجحان، وLint ناجح مع تحذيرين قديمين فقط عن استخدام `<img>` في `IframeStage` و`StudentCard`.

## ملاحظات تشغيلية

خادم الإنتاج يعمل على المنفذ 3000 بعد Build نهائي. البيانات التي أُنشئت أثناء الاختبار بقيت محلية في المتصفح ومجلد التنزيلات، ولم تُضف جلسة أو بيانات صف جديدة إلى قاعدة التسليم.
