# حزمة تجربة بسالسة — فصل رابعة ابتدائي رياضيات

هذه الحزمة تحتوي على **فصل تجريبي كامل**: 12 طالباً، 3 مجموعات، 4 دروس، 12 أفكار، 48 سؤالاً، جلسة حصة، 4 ألعاب، أنشطة ونقاط وشارات واحتفالات وملاحظات.

## الطريقة الأسرع: استعادة كل البيانات مرة واحدة

1. افتح المنصة بوضع المدرس.
2. افتح لوحة **الإعدادات**.
3. اختر **نسخة JSON > استعادة**.
4. اختر الملف `bisalasa-demo-backup.json`.
5. وافق على رسالة الاستبدال.
6. افتح **الفصول** واختر فصل `رابعة ابتدائي — رياضيات — فصل التجربة`.
7. افتح **المنهج** واختر أحد الدروس، ثم جرّب الألعاب والتقارير والطلاب والدرجات.

> الاستعادة تستبدل البيانات الموجودة؛ خذ نسخة JSON من الإعدادات أولاً إذا لديك بيانات مهمة.

## استيراد الدروس كملفات HTML

إذا أردت تجربة زر استيراد المنهج نفسه، افتح لوحة **المنهج** واختر كل الملفات داخل مجلد `lessons` معاً. كل ملف يحتوي على `slide-manifest`، وأربع أسئلة تفاعلية داخل كل فكرة.

## بيانات التجربة

الطلاب موزعون على 3 مجموعات. يوجد طالب غائب، جلسة حصة، نتائج ألعاب، نقاط محلية، شارات، ملاحظات، واحتفالات. تتضمن الحزمة أصلاً تعليمياً SVG جاهزاً للعرض وصور هدايا WebP محلية. أسماء الطلاب وبيانات Moodle تجريبية وليست بيانات حقيقية.


## ملاحظة Moodle

حقول Moodle التجريبية موجودة على الطلاب لاختبار المطابقة والواجهة. لا يتم الاتصال بـMoodle الحقيقي من الملف؛ استخدم mock Moodle أو إعداد التكامل من لوحة الإعدادات إذا أردت اختبار السحب الحي.
