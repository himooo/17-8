# 📘 SLIDE_CONFIGURATION.md — تحديث v9.0 (التعليقات الافتراضية)

## 🆕 الميزة الجديدة: التعليقات الافتراضية (Virtual Comments)

### المفهوم
التعليقات الافتراضية هي **رسائل بابل** تظهر فوق الـ iframe تلقائياً عند الوصول لخطوة معينة. كل bubble فيها:
- **Avatar** الطالب (أيقونة حسب الجنس)
- **اسم** الطالب (من الفصل أو من hint في الـ manifest)
- **نص** التعليق
- **لون** حسب النبرة (confident/confused/excited/curious/neutral)
- **صوت** "بلوب" عند الظهور

### الاستخدام

التعليقات تُكتب في الـ **Manifest** جوه الـ HTML:

```json
{
  "lessonId": "my-lesson",
  "title": "عنوان الدرس",
  "steps": [...],
  "virtualComments": [
    {
      "step": 2,
      "text": "دي سهلة جداً يا مستر!",
      "tone": "confident",
      "studentHint": { "name": "مشمشة", "gender": "female" }
    },
    {
      "step": 5,
      "text": "أنا مش فاهم ليه القاسم مش بيتغير؟",
      "tone": "confused",
      "studentHint": { "name": "بندق", "gender": "male" }
    }
  ]
}
```

### قواعد التعليقات

| القاعدة | الوصف |
|---------|-------|
| `step` | رقم الخطوة (1-based) — التعليق يظهر عند الوصول للخطوة دي |
| `ideaId` | (اختياري) لو الدرس في وضع الأفكار المتداخلة |
| `text` | نص التعليق (2-3 كلمات أو سؤال قصير) |
| `tone` | النبرة: `confident`, `confused`, `excited`, `curious`, `neutral` |
| `studentHint` | (اختياري) تلميح للاسم/الجنس |

### نبرات التعليقات

| النبرة | الاستخدام | لون البابل |
|--------|-----------|-----------|
| `confident` | "دي سهلة"، "أنا عارف" | أخضر |
| `confused` | "أنا مش فاهم"، "إيه ده؟" | أصفر |
| `excited` | "وااو!"، "جميل جدا"! | وردي |
| `curious` | "طيب لو كده إيه؟"، "إزاي؟" | أزرق |
| `neutral` | "تمام", "ماشي" | رمادي |

### التشغيل

1. فعّل الميزة من الإعدادات: **الإعدادات ← التعليقات الافتراضية**
2. اضبط **مدة الاختفاء التلقائي** (الافتراضي: 6 ثواني)
3. في لوحة المفاتيح: اضغط **V** لتشغيل/إيقاف التعليقات فوراً أثناء الدرس

### الترتيب والعدالة

- كل تعليق يستخدم طالب مختلف (fair rotation)
- مش بيأثر على العدالة الحقيقية في الألعاب
- لو الدرس فيه studentHint باسم طالب موجود في الفصل → يستخدمه
- لو مش موجود → يختار طالب عشوائي من الحاضرين

### التفاعل مع الـ Bubble

- **hover**: يوقف الاختفاء التلقائي
- **click**: يغلق فوراً
- **auto-hide**: بعد المدة المحددة (افتراضي 6 ثواني)
